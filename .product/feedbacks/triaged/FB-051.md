`SessionItem` components use the `aria-selected` attribute, but the parent container does not have `role="listbox"` (or `role="tablist"`). The `aria-selected` attribute is only meaningful in the context of `listbox`, `tablist`, `tree`, `grid`, or `treegrid` roles. Without the correct parent role, screen readers will ignore or misinterpret `aria-selected`.

Fix: Either add `role="listbox"` to the sessions list container (with `role="option"` on each item), or switch to `role="tablist"` / `role="tab"` semantics. Alternatively, if selection is not needed for AT, remove `aria-selected` and rely on a CSS class for visual styling only.
