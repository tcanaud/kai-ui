**Severity**: Low

**Reproduction Steps**:
1. Open the app at mobile viewport (375x812)
2. Tap the hamburger menu to open the sidebar sheet
3. Tap "New Session" inside the sheet

**Expected**: Either the sheet closes before the dialog opens, or the flow is streamlined so only one overlay is shown at a time
**Actual**: The New Session dialog (haspopup="dialog") opens on top of the still-open sheet. Both dialogs are layered simultaneously. The user must dismiss two dialogs to return to the main content.

**Fix Suggestion**: When the New Session button is tapped inside the mobile sheet, auto-close the sheet before opening the dialog. Alternatively, close the sheet on any session button click.

**Source**: QA session — mobile UX test.
