**Severity**: LOW

The feature name validation regex `^[a-z0-9][a-z0-9-]*$` is too permissive. It does not reject:
- Trailing hyphens: `trailing-hyphen-` is accepted
- Consecutive hyphens: `double--hyphen` is accepted

Both patterns produce invalid identifiers that can break git branch names, filesystem paths, and slug-based conventions.

**File**: `new-session-dialog.tsx` line 31.

**Fix**: Update the regex to `^[a-z0-9]([a-z0-9]|-(?!-))*[a-z0-9]$` or similar to disallow trailing and consecutive hyphens. Also ensure single-character names remain valid.
