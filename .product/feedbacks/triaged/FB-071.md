**Severity**: medium
**Context**: performance-audit QA session

## Description

The Largest Contentful Paint (LCP) was measured at 3,019ms, exceeding the "needs improvement" threshold of 2,500ms. The root cause is the client-side xterm.js initialization taking approximately 2.8 seconds before the terminal is visible and painted.

## Performance Data

- LCP measured: 3,019ms
- LCP threshold (good): ≤ 2,500ms
- Root cause: xterm.js client-side init = 2.8s

## Suggested Fix

Add a terminal skeleton/placeholder that renders immediately on server (or at hydration) while xterm.js loads asynchronously. This moves the LCP element to a lightweight placeholder, improving perceived performance and the Core Web Vital score. Consider using React `Suspense` with a `lazy()` import for the terminal component.
