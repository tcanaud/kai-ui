In the session creation form, the `<Label>` element has `htmlFor="playbook"` but no form element has `id="playbook"`. This broken association means clicking the label does not focus the control, and screen readers cannot programmatically associate the label with the select/combobox input.

Fix: Add `id="playbook"` to the `SelectTrigger` (or whichever element represents the playbook control), or use the Radix UI pattern of forwarding `id` through the composed component.
