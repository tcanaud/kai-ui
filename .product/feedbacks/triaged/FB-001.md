**Severity**: Critical

**Reproduction Steps**:
1. Ensure the sidecar WebSocket server is running at port 3001 (health check: `{"status":"ok","activeSessions":0}`)
2. Navigate to http://localhost:3000
3. Observe the terminal panel

**Expected**: A live terminal with a shell prompt is displayed
**Actual**: The terminal panel displays "Disconnected. Reconnecting..." status text. The xterm.js input box is present but the panel is in a reconnecting state despite the sidecar being healthy.

**Notes**: The sidecar is running and healthy but the browser-side terminal is not completing the initial connection. This may be a session ID mismatch, a missing session context in the URL, or a timing issue between Next.js render and the WebSocket connection attempt.

**Source**: QA session — browser snapshot during `/qa.run` manual UI verification. Test criterion: US1.AC1.
