The Cumulative Layout Shift (CLS) score is 0.171, which exceeds the "good" threshold of 0.1 (Core Web Vitals). The shift originates from the Editor panel, which changes dimensions after the initial paint. This degrades perceived performance and can cause users to misclick on interactive elements that shift out from under the cursor.

Fix: Reserve space for the Editor panel with explicit dimensions before content loads (e.g. set a `min-height` or use aspect-ratio). Investigate whether a font load, lazy-loaded component, or dynamic content injection is the root cause of the shift and address it at the source.
