**Severity**: MEDIUM

The `SheetContent` in `mobile-nav.tsx` is missing a `SheetTitle` (or visually hidden equivalent). Radix UI emits a console error: "DialogContent requires a DialogTitle for the dialog to be accessible for screen reader users."

**File**: `mobile-nav.tsx` — `SheetContent` component.

**Fix**: Add `<SheetTitle className="sr-only">Navigation</SheetTitle>` (or equivalent) inside the `SheetContent` to satisfy the Radix accessibility requirement without visual impact.

**Note**: FB-009 covers missing `DialogTitle` in dialog components; this finding specifically targets the Sheet (mobile nav sidebar) which uses the same Radix Dialog primitive underneath.
