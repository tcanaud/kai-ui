The Radix UI `Sheet` used in `mobile-nav.tsx` does not include `SheetTitle` or `SheetDescription` components. Radix UI requires these for the dialog role to have an accessible name and description. Their absence triggers a console warning and leaves the dialog region unlabelled for screen readers.

Fix: Add a `SheetTitle` (e.g. "Navigation") inside the `SheetContent`. If a visible title is undesirable, use the Radix `VisuallyHidden` utility. Add a `SheetDescription` as well, or suppress it via `aria-describedby={undefined}` if no description is appropriate.
