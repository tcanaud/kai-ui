Panel divs are assigned `role="button"` to make them keyboard-activatable for expand/collapse. However, the terminal panel contains interactive elements (the xterm terminal, which itself receives keyboard input). Having interactive content nested inside a `role="button"` is invalid ARIA and causes screen readers to either skip the inner content or announce it incorrectly.

Fix: Separate the expand/collapse affordance from the panel container. Use a dedicated button element (e.g. in the panel header) for the collapse/expand action, and remove `role="button"` from the panel wrapper that contains interactive content.
