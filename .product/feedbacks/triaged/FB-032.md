**Severity**: MEDIUM

The Create Session dialog in `new-session-dialog.tsx` is missing an `aria-describedby` attribute pointing to a description element. Radix UI emits a console warning on every dialog open due to this omission. Screen readers cannot announce a description when the dialog opens.

**File**: `new-session-dialog.tsx`

**Fix**: Add a `<DialogDescription>` element (can be visually hidden with `sr-only`) with a brief description of the dialog purpose, and ensure Radix wires it via `aria-describedby` automatically. For example:

```tsx
<DialogDescription className="sr-only">
  Create a new kai session by specifying the target feature name and playbook.
</DialogDescription>
```
