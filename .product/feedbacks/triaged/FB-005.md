**Severity**: Medium

**Reproduction Steps**:
1. Open the New Session dialog
2. Select a playbook and type a feature name
3. Close the dialog via the Close button, Escape key, or clicking outside
4. Reopen the New Session dialog

**Expected**: The dialog opens with a clean empty state — no playbook selected, feature name cleared, no error messages
**Actual**: The previously selected playbook, previously typed feature name, and any error messages from the prior interaction are still shown. The reset logic in `new-session-dialog.tsx` (lines 55-56) only runs on successful submission; `onOpenChange` is set to `setOpen` with no cleanup.

**Fix Suggestion**:
```tsx
function handleOpenChange(isOpen: boolean) {
  setOpen(isOpen);
  if (!isOpen) {
    setSelectedPlaybook("");
    setFeatureName("");
    setError(null);
  }
}
```
