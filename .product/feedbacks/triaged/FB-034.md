**Severity**: LOW

Clicking the "kai ui" header logo/text provides no visual feedback. It is unclear to users whether clicking it does anything (deselect session, navigate home, refresh). If it has a function, it needs a visible affordance. If it has no function, it should not be interactive.

**Fix options**:
1. If the header click deselects the current session: add visual feedback (e.g., cursor:pointer, active state, toast notification).
2. If the header click navigates home: treat it as a link with appropriate hover/focus styles.
3. If it has no action: remove any `onClick` handler and ensure it has `cursor:default`.
