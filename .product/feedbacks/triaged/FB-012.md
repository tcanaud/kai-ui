**Severity**: Low

**Reproduction Steps**:
1. Open the New Session dialog
2. Click "Create Session" to initiate the API request
3. Before the request completes, close the dialog

**Expected**: In-flight API request should be cancelled when the dialog closes, preventing state updates on an unmounted component
**Actual**: No `AbortController` is used. The fetch request continues in the background and may attempt to update React state on an already-unmounted/closed dialog component, which can cause React warnings or unexpected side effects.

**Fix Suggestion**: Use `AbortController` in the form submit handler. Pass `signal` to the `fetch` call and call `controller.abort()` in the `onOpenChange` cleanup or `useEffect` cleanup function.
