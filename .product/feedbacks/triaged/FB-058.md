The `xterm-viewport` element has a computed height of 0px, which causes the xterm scrollbar to not render and terminal scrolling to be broken. Users cannot scroll through terminal history using the scrollbar or mouse wheel.

Root cause: The terminal container does not propagate its height correctly to xterm's internal viewport element, likely because the container lacks explicit height constraints in the CSS layout.

Fix: Ensure the terminal container has a defined height at all times. After fixing the `PanelSlot` height issue (FB-057), verify that `xterm-viewport` receives a non-zero height. Call `fitAddon.fit()` after any layout change that affects the container dimensions.
