The Radix UI `Dialog` in `new-session-dialog.tsx` does not include a `DialogDescription`. Radix UI expects this component to provide an accessible description for the dialog region. Its absence produces a console warning and means screen readers receive no context about the dialog's purpose beyond its title.

Fix: Add a `DialogDescription` with a brief explanation of the dialog's purpose (e.g. "Fill in the details below to start a new kai session."). If no visible description is desired, wrap it in a `VisuallyHidden` component.
