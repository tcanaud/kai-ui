**Severity**: LOW

When loading the terminal panel, it displays stale output from the previous session or connection. There is no clear-on-connect behavior to reset the terminal display when a new WebSocket connection is established.

**Fix options**:
1. Send a `clear` sequence (`\x1b[2J\x1b[H`) to xterm.js when a new connection is established.
2. Call `terminal.clear()` on the xterm instance at WebSocket `open` event.
3. Alternatively, preserve scrollback but scroll to bottom so users see current prompt — only clear if the session is new vs. reconnect.

Consider making clear-on-connect a user-configurable option to support both "fresh start" and "resume session" use cases.
