On mobile and tablet viewports, the fixed-position hamburger menu button overlaps the terminal panel header. The main content area has no top padding to account for the mobile navigation bar, causing the panel header to render beneath the hamburger button and making it inaccessible.

Fix: Add sufficient top padding or margin to the main content area on mobile viewports to clear the mobile navigation bar height. Alternatively, apply `padding-top` equal to the nav bar height using a CSS variable or Tailwind spacing token.
