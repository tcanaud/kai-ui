When the playbook list fetch fails, the `catch` block silently sets the playbooks array to empty (`[]`) without surfacing any error message to the user. The user sees an empty dropdown with no indication that something went wrong, which can lead to confusion or accidental session creation with no playbook selected.

Fix: Display an inline error message (or toast) when the playbook fetch fails, explaining that the list could not be loaded and offering a retry action.
