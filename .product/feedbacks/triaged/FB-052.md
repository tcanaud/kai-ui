Error messages displayed in the session creation form (e.g. validation errors, API errors) are rendered visually but not announced to screen readers. They lack `role="alert"` or `aria-live="assertive"`, so users relying on screen readers receive no notification when an error occurs.

Fix: Add `role="alert"` (or `aria-live="assertive"`) to the error message container. This ensures screen readers announce the error immediately when it appears without requiring the user to navigate to it.
