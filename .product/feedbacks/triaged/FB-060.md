Panel borders show no visual change on hover. Users get no feedback to confirm that hovering over a panel is meaningful or that the panel is interactive. This is particularly confusing alongside the missing cursor affordance (see FB-059).

Fix: Add a hover state to panel borders (e.g. a subtle border color change or background highlight using `hover:border-primary` or equivalent Tailwind utility). Ensure the hover style is applied to the same element that has `role="button"` so the affordance is spatially consistent.
