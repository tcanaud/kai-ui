Chrome DevTools coverage analysis shows 377 KiB of JavaScript from the xterm library is loaded and parsed on initial page load but never executed, because the terminal panel is not visible by default. This unnecessarily inflates the initial bundle size, increasing Time to Interactive.

Fix: Lazy-load the xterm library using dynamic `import()` (e.g. `const { Terminal } = await import('@xterm/xterm')`) only when the terminal panel is first made visible. Use Next.js `dynamic()` with `{ ssr: false }` for the terminal component to achieve this without SSR issues.
