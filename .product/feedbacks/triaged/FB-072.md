**Severity**: low
**Context**: performance-audit QA session

## Description

`xterm.css` is loaded as a blocking stylesheet in the critical path, delaying initial render. The terminal is not visible until xterm.js initializes (which happens client-side after page load), so blocking the page render on xterm styles provides no user benefit.

## Suggested Fix

Load xterm.css asynchronously alongside the lazy-loaded xterm.js module. When xterm is loaded lazily (e.g., via `React.lazy()` or dynamic `import()`), import xterm.css inside that module so it only blocks terminal rendering (not the full page). This can be combined with the FB-071 terminal skeleton improvement.
