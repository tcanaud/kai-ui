**Test Script**: Manual MCP Chrome DevTools test (dialog accessibility)
**Criterion**: General accessibility — WCAG dialog pattern
**Observation**: Opening the "Create Session" dialog produces two console warnings: `Warning: Missing Description or aria-describedby={undefined} for {DialogContent}`. The dialog lacks an `aria-describedby` attribute linking to a description element.
**Severity**: non-blocking
**Suggestion**: Add a `DialogDescription` (or visually hidden description) inside `DialogContent`, or pass `aria-describedby` to the dialog content wrapper to satisfy the Radix UI accessibility contract.
