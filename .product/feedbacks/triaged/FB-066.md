**Severity**: low
**Context**: session-creation-adversarial, keyboard-a11y QA session

## Description

Opening the "Create Session" dialog produces console warnings: `Warning: Missing 'Description' or 'aria-describedby={undefined}' for {DialogContent}`. The dialog lacks an `aria-describedby` attribute linking to a description element, violating WCAG 4.1.2.

## Reproduction Steps

1. Open the app and click "New Session"
2. Observe the browser console
3. **Observed**: Console warns `Missing Description or aria-describedby` for DialogContent on each open.
4. **Expected**: No console warnings; dialog has a proper description for screen readers.

## Suggested Fix

Add a `DialogDescription` (with `sr-only` class if not visually needed) inside `DialogContent` in `new-session-dialog.tsx`. For example:
```tsx
<DialogDescription className="sr-only">
  Create a new kai session by selecting a playbook and entering a feature name.
</DialogDescription>
```
