**Severity**: Low

**Finding**: The Geist font WOFF2 file is loaded in the critical rendering path, taking 331ms. This contributes to font swap/flash and delays text rendering.

**Fix Suggestion**: Add `<link rel="preload" as="font" type="font/woff2" href="..." crossorigin>` in the `<head>` for the Geist font to start loading it earlier. If using Next.js `next/font`, verify the font is configured with `display: "swap"` and that preloading is enabled.

**Source**: QA session — performance trace via Chrome DevTools.
