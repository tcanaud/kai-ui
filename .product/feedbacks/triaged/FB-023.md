**Severity**: MEDIUM

The Create Session dialog requires two clicks on the close button to actually close. The first click resets the form state but does not close the dialog. The second click then closes it.

**Root cause**: The Radix Select component reset during the close cycle interferes with dialog open state. When `handleOpenChange(false)` is called, the Select reset triggers a state update that re-opens or holds the dialog open.

**File**: `new-session-dialog.tsx` — `handleOpenChange` function.

**Steps to reproduce**:
1. Open the Create Session dialog
2. Click the X close button once
3. Observe: form fields reset but dialog remains open
4. Click X again to actually close

**Expected**: Single click on X closes the dialog immediately.
