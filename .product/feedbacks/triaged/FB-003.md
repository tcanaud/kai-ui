**Severity**: Critical

**Reproduction Steps**:
1. Open the app in a browser
2. Click the terminal panel to focus it
3. Press Tab repeatedly
4. Attempt to navigate to other UI elements (sidebar, buttons, etc.)

**Expected**: Tab key navigates focus to the next focusable element outside the terminal
**Actual**: Tab is captured by the xterm.js textarea and never reaches other UI elements. Keyboard-only users are stuck and cannot reach any other part of the interface.

**Notes**: This is a WCAG 2.1 failure (Success Criterion 2.1.2 — No Keyboard Trap). The xterm.js `xterm-helper-textarea` consumes Tab input as a terminal character rather than allowing browser focus management. A common fix is to intercept Tab and Shift+Tab in the terminal's key handler and call `blur()` / move focus programmatically, or implement an Escape-to-exit pattern.

**Source**: QA session — keyboard navigation testing.
