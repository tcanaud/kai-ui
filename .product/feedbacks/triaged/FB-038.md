**Severity**: INFO

The playbook selection list in the Create Session dialog includes internal/template entries such as `autohotfix-old` and `playbook.tpl` that should not be visible to end users. These are development artifacts or template files.

**Fix**: Filter the playbook list on the server or client to exclude:
- Entries ending in `.tpl` (template files)
- Entries with `-old` suffix (deprecated/archived playbooks)
- Any entries starting with `_` (convention for internal/hidden items)

Consider adding a naming convention (e.g., prefix with `_` for hidden playbooks) so the filtering rule is explicit and maintainable.
