The xterm.js terminal input area currently has no visible focus ring or indicator when focused via keyboard. Keyboard users cannot tell when the terminal is focused without typing a character. A visible focus indicator (e.g., a bright neon border or glow on the terminal panel container) would align with WCAG 2.1 SC 2.4.7 (Focus Visible) and improve the overall keyboard navigation experience.

Suggested approach: Add a CSS `focus-within` style on the terminal panel container that highlights the border when the xterm textarea is focused (e.g., `focus-within:ring-2 focus-within:ring-cyan-400`).

**Source**: QA session — UX improvement idea.
