Related to the Tab-focus-trap bug (FB-003), consider implementing an Escape-to-exit pattern for the terminal panel. When the terminal is focused and the user presses Escape (or a configurable key combination like Ctrl+Shift+M), focus would be returned to the panel grid or the next focusable element outside the terminal.

This pattern is used by VS Code (F6 to move focus out of terminal) and would resolve the keyboard trap issue while preserving Escape's default terminal behaviour (e.g., for shell readline). Consider showing a tooltip or status bar hint like "Press Escape to exit terminal focus" when the terminal is first activated.
