**Severity**: Low

**Reproduction Steps**:
1. Open the New Session dialog
2. Paste 200+ characters into the feature name field
3. Observe the input accepts all characters without truncation

**Expected**: Input should enforce a maximum length appropriate for filesystem and git branch name constraints
**Actual**: There is no `maxLength` constraint on the input element, allowing arbitrarily long feature names that may fail at the filesystem or git layer downstream.

**Fix Suggestion**: Add `maxLength={100}` to the feature name `<input>` element in the New Session dialog.

**Source**: QA session — input validation edge case testing.
