**Severity**: Low

**Console Error**: "A form field element should have an id or name attribute"

**Observation**: The browser console reports an accessibility issue for the `xterm-helper-textarea` inside the xterm.js DOM renderer. The element has `aria-label="Terminal input"` but no `id` or `name` attribute. This is an internal xterm.js implementation detail, not directly controllable from application code. The `aria-label` is present so screen reader support is not impacted, but the console warning is noisy.

**Fix Suggestion**: Investigate whether the current xterm.js version supports a configuration option to set or suppress an `id` on the helper textarea. Alternatively, consider upgrading to a newer `@xterm/xterm` release that may have resolved this. As a last resort, a post-render DOM patch could be used to add the attribute.

**Source**: QA session — accessibility audit, test criterion: IF1.
