**Severity**: Medium

**Finding**: Largest Contentful Paint (LCP) measured at 3,729ms. Chrome DevTools performance trace attributes 98.5% of the LCP delay to render delay caused by JavaScript bundle size and/or Next.js hydration cost.

**Impact**: Google Core Web Vitals classify LCP > 2,500ms as "Needs Improvement" (> 4,000ms = "Poor"). This impacts perceived performance for all users on initial load.

**Investigation Areas**:
- Identify the largest JS chunks contributing to the bundle (xterm.js, React, other heavy dependencies)
- Consider lazy-loading the terminal panel and xterm.js until the panel is first activated
- Evaluate Next.js dynamic imports (`next/dynamic`) with `ssr: false` for client-only components
- Profile hydration cost in React DevTools

**Source**: QA session — performance trace via Chrome DevTools.
