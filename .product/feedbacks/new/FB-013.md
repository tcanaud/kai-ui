**Severity**: Low

**Reproduction Steps**:
1. Open the app
2. Hover over any panel card in the main grid
3. Observe the cursor style

**Expected**: Cursor changes to a pointer (hand) on hover to indicate the element is clickable
**Actual**: `cursor: auto` is applied despite each panel's outer wrapper div having a React `onClick` handler (`handlePanelClick`). Users receive no visual affordance that panels are clickable.

**Fix Suggestion**: Add `cursor-pointer` Tailwind class to each panel wrapper div in the grid layout (the divs wrapping the `PanelSlot` card).

**Source**: QA session — visual integration test. Test criterion: US4.AC3.
