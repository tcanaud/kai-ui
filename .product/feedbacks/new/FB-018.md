Panel cards in the main grid have click handlers but provide no visual feedback on hover. Adding hover states (e.g., a subtle border glow, background lightening, or scale transform) would improve perceived interactivity and help users discover that panels are clickable before they click.

Suggested approach: Add a Tailwind `hover:` variant to the panel wrapper (e.g., `hover:border-cyan-500/50 hover:shadow-md transition-all`) consistent with the existing neon cyberpunk aesthetic.

**Source**: QA session — UX improvement idea.
