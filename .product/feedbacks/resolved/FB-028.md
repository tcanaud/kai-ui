**Severity**: MAJOR

All 5 panel wrapper `<div>` elements in `panel-layout.tsx` have `tabIndex=-1`, no `role` attribute, and no `aria-label`. This makes panels completely unreachable via keyboard Tab navigation. Users relying solely on keyboard cannot access or activate any panel.

**File**: `panel-layout.tsx` — panel wrapper divs.

**WCAG violation**: 2.1.1 Keyboard (Level A) — all functionality must be operable via keyboard.

**Fix**:
- Set `tabIndex={0}` on all panel wrappers
- Add `role="button"` or `role="tab"` as appropriate
- Add descriptive `aria-label` (e.g., `aria-label="Terminal panel"`)
- Handle `onKeyDown` for Enter/Space to activate panel selection
