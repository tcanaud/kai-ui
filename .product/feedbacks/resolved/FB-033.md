**Severity**: MEDIUM

The session sidebar in `session-sidebar.tsx` does not use a `<nav>` landmark element and there is no skip-navigation link. With 11+ session buttons in the sidebar, keyboard-only users must tab through every session button before reaching the main content area.

**File**: `session-sidebar.tsx`

**WCAG violation**: 2.4.1 Bypass Blocks (Level A) — a mechanism must exist to bypass repeated navigation blocks.

**Fix**:
1. Wrap the sidebar in `<nav aria-label="Sessions">` to provide a landmark.
2. Add a visually hidden skip link at the top of the page: `<a href="#main-content" className="sr-only focus:not-sr-only">Skip to main content</a>`.
3. Add `id="main-content"` to the main panel area.
