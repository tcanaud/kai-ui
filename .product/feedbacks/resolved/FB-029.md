**Severity**: MAJOR

When a panel is active (cyan glow border), the selection state is conveyed visually only. The accessibility tree has no `aria-selected`, `aria-pressed`, or `aria-current` attribute reflecting the active state. Screen reader users cannot determine which panel is currently active.

**File**: `panel-layout.tsx` — panel wrapper divs.

**WCAG violation**: 1.3.1 Info and Relationships (Level A) — information conveyed through presentation must be programmatically determinable.

**Fix**: Add `aria-selected={isActive}` (if using `role="tab"`) or `aria-pressed={isActive}` (if using `role="button"`) to the panel wrapper that reflects the current active panel state.
