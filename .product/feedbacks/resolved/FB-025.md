**Severity**: HIGH

On mobile, clicking the X button inside the sheet does not dismiss it. The Escape key works correctly, but the visual close button is non-functional.

**Root cause**: The `SheetPrimitive.Close` click event is not propagating — likely stopped by an event handler in a parent element or a z-index/pointer-events issue preventing the click from reaching the Radix Close primitive.

**Files**: `mobile-nav.tsx`, `sheet.tsx`

**Steps to reproduce**:
1. Open the app on a mobile viewport
2. Tap the hamburger menu to open the sheet
3. Tap the X close button
4. Observe: sheet does not close
5. Press Escape — sheet closes correctly

**Expected**: Tapping the X button closes the sheet on first tap.

**Note**: This is related but distinct from FB-002 (intermittent sheet close failure) — this specifically identifies the X button click as the failure point and `SheetPrimitive.Close` event propagation as the root cause.
