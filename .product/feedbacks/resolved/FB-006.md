**Severity**: Medium

**Reproduction Steps**:
1. Open the New Session dialog
2. In the feature name field, enter a string containing special characters such as `!@#$%^&*(){}[]|\:";'<>,.?/~\``
3. Observe that the submit button is enabled
4. Submit the form

**Expected**: The form should reject invalid characters and display a validation error
**Actual**: Special characters are accepted without any validation. Feature names are used as directory names and git branch names downstream — characters like `/`, `\`, `*`, `?`, `:`, `"`, `<`, `>`, `|` will cause filesystem or git errors.

**Fix Suggestion**:
- Add a regex pattern for valid feature names: `/^[a-z0-9][a-z0-9-]*$/`
- Display an inline validation error when the pattern is not matched
- Also add `maxLength={100}` on the input element

**Source**: QA session — manual exploratory test, session creation dialog.
