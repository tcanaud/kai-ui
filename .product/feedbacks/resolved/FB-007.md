**Severity**: Medium

**Reproduction Steps**:
1. Open the New Session dialog
2. In the feature name field, enter only spaces (e.g., "   ")
3. Observe that the submit button becomes enabled

**Expected**: Whitespace-only input should be treated as empty and the submit button should remain disabled
**Actual**: The current validation only checks for a truthy string value — `!featureName` — which passes for non-empty whitespace strings. The submit button is enabled and the form can be submitted with a blank name.

**Fix Suggestion**: Change the validation condition to `!featureName.trim()` so whitespace-only strings are treated as invalid.

**Source**: QA session — manual exploratory test, session creation dialog.
