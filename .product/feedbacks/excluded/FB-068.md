**Severity**: low
**Context**: session-creation-adversarial QA session

## Description

The feature name validation regex currently accepts names like `"feature-"` (trailing hyphen). The name should be required to end with an alphanumeric character to produce valid git branch and filesystem path names.

## Reproduction Steps

1. Open the "New Session" dialog
2. Enter a feature name ending with a hyphen, e.g. `"my-feature-"`
3. **Observed**: The input passes client-side validation and the form can be submitted.
4. **Expected**: Validation error — name must end with a letter or number.

## Suggested Fix

Tighten the validation regex to require the name to end with an alphanumeric character. For example, change from:
```
/^[a-z0-9][a-z0-9-]*$/
```
to:
```
/^[a-z0-9][a-z0-9-]*[a-z0-9]$|^[a-z0-9]$/
```
(or equivalent) to disallow trailing hyphens.
