**Context**: session-creation-adversarial QA session

## Description

The `playbook.tpl` template file (and potentially other template/deprecated entries) appears as a selectable option in the playbook dropdown in the New Session dialog. Template files should not be visible to users as selectable playbooks.

## Reproduction Steps

1. Open the "New Session" dialog
2. Click the Playbook dropdown
3. **Observed**: `playbook.tpl` appears as a selectable option alongside real playbooks.
4. **Expected**: Only valid, user-facing playbooks appear; template files are filtered out.

## Suggested Fix

Filter the playbook list server-side or client-side to exclude files matching patterns like `*.tpl`, `*.template`, `autohotfix-old`, or any file not ending in `.yaml`/`.yml` with a valid playbook structure.
