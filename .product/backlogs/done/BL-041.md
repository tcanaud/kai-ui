Two accessibility regressions detected in `mobile-nav.tsx` after the feature-007 keyboard accessibility fix:

1. **Missing hamburger aria-label** (FB-045): The hamburger menu button has no `aria-label`, so screen readers announce it as a bare "button" with no purpose. Fix: add `aria-label="Open navigation menu"` (toggling to "Close navigation menu" when open) and `aria-expanded` accordingly.

2. **Missing SheetTitle and SheetDescription** (FB-046): The Radix UI `Sheet` in mobile-nav lacks `SheetTitle` and `SheetDescription`, leaving the dialog region unlabelled for screen readers and triggering a Radix console warning. Fix: add `SheetTitle` (e.g. "Navigation") — use `VisuallyHidden` if a visible title is undesirable — and either a `SheetDescription` or `aria-describedby={undefined}`.

These regressions indicate the accessibility fix in feature-007 did not cover the mobile navigation component.
