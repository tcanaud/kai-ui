On mobile viewports, tapping the X close button inside the sheet does not dismiss it. The Escape key works correctly, but the visual close button is non-functional. The Radix `SheetPrimitive.Close` click event is not propagating — likely stopped by an event handler on a parent element or a z-index/pointer-events issue.

**Files**: `mobile-nav.tsx`, `sheet.tsx`.

**Note**: This is related but distinct from the previously resolved FB-002 (intermittent sheet close failure). FB-002 addressed intermittent close failures broadly; this specifically identifies the X button as the failure point and `SheetPrimitive.Close` event propagation as the root cause.

**Acceptance criteria**:
- A single tap on the X button closes the sheet on mobile.
- Escape key continues to work.
- No regression on desktop close behavior.
