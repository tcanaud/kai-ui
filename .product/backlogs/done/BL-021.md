Three related mobile and responsive layout issues:

1. **FB-002 — Sheet cannot be closed (Critical)**: The mobile sidebar Sheet overlay cannot be dismissed via the close button, backdrop click, or Escape key. `data-state` stays "open". The Sheet in `mobile-nav.tsx` is used in uncontrolled mode; switching to controlled state (`open`/`onOpenChange`) should resolve this.

2. **FB-008 — Tablet 768px cramped layout**: At 768x1024 the full desktop sidebar (~270px) renders without a hamburger fallback, leaving ~500px for the 3-column panel grid (~160px per panel). A breakpoint needs to be added to collapse the sidebar into a sheet at tablet widths.

3. **FB-015 — Nested dialogs on mobile**: Opening "New Session" from within the mobile sheet stacks two modal overlays simultaneously. The sheet should auto-close before the dialog opens on mobile.

**Acceptance Criteria**:
- Mobile sheet can be closed via X button, backdrop tap, and Escape key
- At 768px viewport, sidebar collapses to hamburger/sheet navigation
- "New Session" from the mobile sheet closes the sheet before opening the dialog
