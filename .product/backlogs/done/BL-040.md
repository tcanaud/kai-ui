When the playbook list fetch fails, the catch block silently sets the playbooks array to empty (`[]`) without surfacing any error to the user. The session dialog shows an empty dropdown with no explanation, which can lead to confusion or accidental submission with no playbook selected.

**Fix**: Display an inline error message (or toast notification) when the playbook fetch fails, explaining that the list could not be loaded and offering a retry action. The error state should be visually distinct from a legitimately empty playbook list.
