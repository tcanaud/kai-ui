Multiple WCAG Level A and AA violations affecting keyboard-only and screen reader users across panel layout, session sidebar, and navigation:

**FB-028** — Panels not keyboard accessible: all 5 panel wrapper `<div>` elements in `panel-layout.tsx` have `tabIndex=-1`, no `role`, and no `aria-label`. Violates WCAG 2.1.1 Keyboard (Level A).

**FB-029** — Active panel state not exposed: the cyan glow border indicating active panel is visual-only. No `aria-selected`, `aria-pressed`, or `aria-current` is set. Violates WCAG 1.3.1 Info and Relationships (Level A).

**FB-030** — Focus and selection indistinguishable: in `session-sidebar.tsx`, focused and selected session buttons share the same cyan border style. Violates WCAG 1.4.1 Use of Color (Level A).

**FB-031** — Faint focus indicator on New Session button: `outline:none` with faint `box-shadow` glow likely fails WCAG 2.4.7 Focus Visible (Level AA).

**FB-033** — No nav landmark or skip link: `session-sidebar.tsx` lacks a `<nav>` landmark and there is no skip-navigation link. With 11+ session buttons, keyboard users must tab through all of them. Violates WCAG 2.4.1 Bypass Blocks (Level A).

**Required fixes**:
- Set `tabIndex={0}`, `role="tab"` or `role="button"`, and `aria-label` on panel wrappers in `panel-layout.tsx`.
- Add `aria-selected={isActive}` or `aria-pressed={isActive}` to reflect active panel state.
- Differentiate focus ring from selected state on session buttons (e.g., dashed outline for focus, solid border for selection).
- Replace `outline:none` on New Session button with `focus-visible:ring-2 focus-visible:ring-white`.
- Wrap sidebar in `<nav aria-label="Sessions">` and add a visually-hidden skip link targeting `#main-content`.

**Acceptance criteria**:
- All panels are reachable and activatable via keyboard Tab and Enter/Space.
- Active panel state is announced by screen readers.
- Focus and selected states are visually distinguishable without relying solely on color.
- New Session button has a visible, WCAG-compliant focus indicator.
- Keyboard users can skip past the session list to main content.
