Once a playbook is selected in the session creation dialog, there is no way to deselect it and proceed without a playbook. Users who accidentally select a playbook are forced to close and reopen the dialog.

**Current behavior**: The Radix Select component does not expose a "none/clear" option once a value is chosen.

**Expected behavior**: Users should be able to return the playbook selection to an unset/empty state. A "(none)" or "— no playbook —" option at the top of the list, or a clear button alongside the select, would solve this.

**File**: `new-session-dialog.tsx` — playbook Select component.

**Fix**:
- Add an explicit empty/none option as the first item in the playbook dropdown
- Or add a small "×" clear button adjacent to the select when a value is chosen
- Ensure the form submits correctly when no playbook is selected (existing path, just needs to be reachable again)
