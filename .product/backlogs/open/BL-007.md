## State Persistence — .kaiui/

Introduce a `.kaiui/` directory for persisting UI state across browser sessions: panel layouts, user preferences, theme customizations, and session pinning.

### Scope

- Create `.kaiui/` directory on first launch
- Persist panel layout preferences per session
- Persist global preferences (theme variant, sidebar width, font size)
- Persist pinned/favorite sessions
- YAML-based state files (following kai file-based philosophy)
- State recovery on browser reopen

### Target Version

V2.0
