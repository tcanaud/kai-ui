## Notification System

Toast notification system for surfacing events: session creation complete, agreement drift detected, QA results, command completion.

### Scope

- Toast component with cyberpunk styling (neon border glow)
- Event types: success, warning, error, info
- Auto-dismiss with configurable duration
- Notification history panel (accessible from header)
- Integrate with file watcher for automated alerts

### Target Version

V2.5
