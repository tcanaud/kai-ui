Three related UX polish issues that reduce discoverability and feedback for panel interactions:

1. **FB-013 — Missing cursor:pointer**: Panel wrapper divs have `onClick` handlers but render `cursor: auto`. Users get no visual hint that panels are clickable. Add `cursor-pointer` Tailwind class to each panel wrapper.

2. **FB-018 — No hover states**: Panel cards have no hover visual feedback. Add hover styles consistent with the cyberpunk aesthetic (e.g., `hover:border-cyan-500/50 hover:shadow-md transition-all`).

3. **FB-021 — Deselect no feedback**: Clicking an already-active panel deselects it with no animation or affordance. Either add a visual cue (tooltip or animation) to signal the toggle, or remove toggle-deselect behaviour and replace with an explicit deselect control.

**Acceptance Criteria**:
- Hovering over any panel card shows a pointer cursor and a hover highlight
- Clicking an active panel either gives clear visual deselect feedback or does not toggle off
