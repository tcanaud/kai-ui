Two distinct Radix accessibility requirements are unmet, each causing console errors on every render:

1. **FB-027** — `SheetContent` in `mobile-nav.tsx` is missing a `SheetTitle` (or visually hidden equivalent). Radix emits: "DialogContent requires a DialogTitle for the dialog to be accessible for screen reader users."

2. **FB-032** — Create Session dialog in `new-session-dialog.tsx` is missing an `aria-describedby` pointing to a `DialogDescription`. Radix emits a console warning on every dialog open, and screen readers cannot announce a description when the dialog opens.

**Fixes**:
- Add `<SheetTitle className="sr-only">Navigation</SheetTitle>` inside the mobile nav `SheetContent`.
- Add `<DialogDescription className="sr-only">Create a new kai session by specifying the target feature name and playbook.</DialogDescription>` inside the Create Session dialog.

**Note**: Related to BL-024 (dialog titles, form labels) but targeting the Sheet component and `aria-describedby` gap which BL-024 does not cover.

**Acceptance criteria**:
- No Radix accessibility console errors on mobile nav sheet open.
- No Radix accessibility console warnings on Create Session dialog open.
- Screen readers announce the navigation sheet and dialog descriptions correctly.
