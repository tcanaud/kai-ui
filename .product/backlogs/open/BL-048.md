The Cumulative Layout Shift (CLS) score is 0.171, exceeding the Core Web Vitals "good" threshold of 0.1. The shift originates from the Editor panel changing dimensions after the initial paint, degrading perceived performance and potentially causing misclicks on interactive elements that shift position.

**Fix**:
- Reserve space for the Editor panel with explicit dimensions before content loads (e.g. `min-height` or `aspect-ratio`).
- Investigate the root cause: likely a font load event, lazy-loaded component, or dynamic content injection.
- Address at the source rather than with layout tricks where possible.
