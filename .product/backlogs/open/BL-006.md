## Panel Drag-and-Drop Layout

Allow users to freely rearrange, resize, minimize, and maximize panels within a session view. Persist layout preferences.

### Scope

- Drag-and-drop panel reordering
- Flexible grid system (panels can span multiple columns/rows)
- Minimize/maximize individual panels
- Layout presets (e.g., "code focus", "review mode", "full terminal")
- Persist layout per session in `.kaiui/layouts/`

### Target Version

V2.0
