## Kai Governance Dashboard

Add a dedicated view (accessible from sidebar) that reads kai governance files and displays the project health: feature lifecycle, agreement status, knowledge freshness, ADR index.

### Scope

- Read `.features/index.yaml` and display feature list with stages
- Read `.agreements/` and show agreement check status (PASS/FAIL/MISSING)
- Read `.knowledge/` and show freshness (VERIFIED/STALE)
- Read `.adr/` and list active ADRs
- Health score computed from all subsystems
- Drill-down into individual features with full lineage

### Target Version

V2.0
