On mobile, tapping "New Session" from the open navigation Sheet may display both the Sheet and the New Session dialog simultaneously. The full prop-threading chain required for sequential close-then-open behavior is absent.

**Root cause** (FB-067, FB-076):
- `NewSessionDialog` has no `onBeforeOpen` prop and does not call it when opening
- `SessionSidebar` has no `onNavigate` prop
- `MobileNav` does not pass `handleCloseSheet` as `onNavigate` to `SessionSidebar`

**Fix**:
1. Add `onBeforeOpen?: () => void` to `NewSessionDialogProps`
2. Call `onBeforeOpen?.()` in `handleOpenChange` when `isOpen=true`
3. Add `onNavigate` prop to `SessionSidebar` and thread it as `onBeforeOpen` to `NewSessionDialog`
4. Pass `handleCloseSheet` as `onNavigate` from `MobileNav` to `SessionSidebar`

**Acceptance criteria**:
- Given the mobile nav sheet is open, when the user taps "New Session", the sheet closes before the New Session dialog opens.
- No simultaneous sheet + dialog state is possible.
