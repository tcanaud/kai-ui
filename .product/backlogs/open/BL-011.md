## Theme Engine

Allow switching between cyberpunk theme variants and creating custom themes with different neon color palettes.

### Scope

- Built-in theme variants: Cyan (default), Magenta, Violet, Matrix Green
- Theme switcher in sidebar footer
- Custom theme support via `.kaiui/theme.yaml` (override CSS variables)
- Propagate theme to embedded code-server and terminal
- Smooth theme transition animations

### Target Version

V2.5
