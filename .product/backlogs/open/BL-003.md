## Playbook Dashboard Panel

Replace the playbook placeholder with a real-time dashboard showing the active playbook session state — current step, journal entries, step completion status.

### Scope

- Read `.playbooks/sessions/{id}/session.yaml` and `journal.yaml` in real-time
- Display playbook steps with completion status (done, in-progress, pending)
- Show journal entries as a timeline
- Highlight current active step
- Auto-refresh on filesystem changes (polling or file watcher)

### Target Version

V1.3
