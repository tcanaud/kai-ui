## Multi-Terminal Support

Allow splitting the terminal panel into multiple panes (horizontal/vertical), each connected to different tmux windows or sessions.

### Scope

- Split terminal panel horizontally or vertically
- Each split pane connects to a different tmux window
- Tab bar showing available tmux windows
- Keyboard shortcuts for navigation between panes (ctrl+shift+arrows)
- Pane close/merge operations

### Target Version

V2.5
