Two complementary UX improvements for keyboard navigation in and around the terminal panel:

1. **FB-019 — Visible focus indicator**: The xterm.js input area has no visible focus ring when focused by keyboard. Add a `focus-within` CSS rule on the terminal panel container to show a neon border/glow when the xterm textarea is focused (e.g., `focus-within:ring-2 focus-within:ring-cyan-400`). Addresses WCAG 2.1 SC 2.4.7 (Focus Visible).

2. **FB-020 — Escape-to-exit-terminal pattern**: Related to the Tab trap (BL-020), implement an Escape-based exit so pressing Escape while the terminal is focused returns focus to the panel grid or next focusable element. Show a status-bar hint (e.g., "Press Escape to exit terminal") when the terminal is first activated. Inspired by VS Code's F6 pattern.

**Acceptance Criteria**:
- A visible focus ring appears on the terminal container when the xterm textarea is focused
- Pressing Escape while the terminal is focused moves focus outside the terminal panel
- A subtle hint informs the user about the Escape-to-exit shortcut on first focus
