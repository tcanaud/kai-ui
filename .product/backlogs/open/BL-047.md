Two related UX affordance gaps on panel containers:

1. **Missing cursor:pointer** (FB-059): Panel divs with `role="button"` do not have `cursor: pointer`. Unlike native `<button>` elements, divs don't inherit pointer cursor styling by default. Users have no visual affordance that the panels are clickable. Fix: add `cursor-pointer` (Tailwind) consistently to all interactive panel headers/containers.

2. **No hover visual feedback on panel borders** (FB-060): Panel borders show no visual change on hover, giving no confirmation that hovering is meaningful. Fix: add a hover border color change (e.g. `hover:border-primary`) to the same element bearing `role="button"` for spatial consistency.

Note: FB-059 is related to the previously triaged FB-013 (cursor:pointer missing on panel wrappers), which was already captured in BL-025. Consider merging into BL-025 or treating this as a follow-up if FB-013 has not been resolved by the time this is worked on.
