## Multi-Project Support

Allow kai-ui to manage multiple kai-enabled project roots from a single instance. Switch between projects without restarting.

### Scope

- Project picker in sidebar header (dropdown or dedicated view)
- Register projects: scan parent directories or manual add via settings
- Each project maintains its own session list and governance state
- Quick switch without server restart (re-point `KAI_PROJECT_ROOT`)
- Recent projects list persisted in `~/.kaiui/projects.yaml`

### Target Version

V3.0
