## Git Integration Panel

A new panel type (6th) for visual git operations: branch graph, worktree status, diff viewer, commit history, and PR status.

### Scope

- Branch graph visualization (Mermaid or custom SVG)
- Worktree list with status indicators
- Inline diff viewer for staged/unstaged changes
- Commit history timeline per session worktree
- PR status integration (via `gh` CLI)
- Quick actions: stage, commit, push, create PR

### Target Version

V3.0
