## Desktop App — Electron or Tauri Wrapper

Package kai-ui as a standalone desktop application for a native experience: system tray, native keyboard shortcuts, file associations, auto-launch.

### Scope

- Evaluate Electron vs Tauri (Tauri preferred for smaller bundle)
- Native window management (frameless window with custom title bar)
- System tray icon with quick session access
- Native file associations for `.kaiui` files
- Auto-update mechanism
- `brew install kai-ui` or direct download

### Target Version

V3.0
