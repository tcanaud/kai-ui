## Session Management

Extend session sidebar with management operations: archive completed sessions, delete abandoned ones, rename sessions, and filter/search.

### Scope

- Right-click context menu on sessions (archive, delete, rename)
- Archive: move session to `.playbooks/sessions/_archive/`
- Delete: remove worktree and session directory (with confirmation)
- Rename: update session.yaml name field
- Search/filter bar in sidebar
- Sort by: name, date, status

### Target Version

V2.0
