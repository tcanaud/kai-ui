## Plugin System

Allow third-party panel extensions that can be installed and loaded into the panel system. Each plugin registers as a new panel type.

### Scope

- Plugin manifest format (`.kaiui/plugins/{name}/manifest.yaml`)
- Plugin API: register panel type, access session context, communicate with other panels
- Plugin discovery: scan `.kaiui/plugins/` on startup
- Built-in plugin: Mermaid diagram viewer (reads `.bmad_output/mermaid/`)
- Security: plugins run in sandboxed iframes with message-passing API

### Target Version

V3.0
