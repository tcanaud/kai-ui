## Keybinding System

Global keyboard shortcut system for navigating between panels, sessions, and executing commands without touching the mouse.

### Scope

- Global keybinding manager (captures shortcuts when not focused in terminal/editor)
- Panel navigation: ctrl+1-5 to focus specific panels
- Session switching: ctrl+shift+up/down
- Command palette: ctrl+k to open a searchable command palette
- Customizable keybindings via `.kaiui/keybindings.yaml`
- Vim-style mode hints in status bar

### Target Version

V2.5
