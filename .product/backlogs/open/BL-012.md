## Real-Time File Watcher

WebSocket-based file watcher that pushes filesystem changes to the UI in real-time. Enables live updates to playbook dashboard, governance views, and session list.

### Scope

- Backend file watcher using `node:fs.watch` on key directories
- WebSocket server for pushing change events to the client
- Client-side event handler that triggers UI refreshes
- Watch: `.playbooks/sessions/`, `.features/`, `.agreements/`, `.qa/`
- Debounced updates to avoid flooding

### Target Version

V2.0
