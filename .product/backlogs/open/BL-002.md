## Code Editor Panel — code-server

Replace the editor placeholder with an embedded code-server (VS Code in browser) instance pointing at the session's worktree.

### Scope

- Embed code-server iframe in the editor panel slot
- Auto-configure workspace to the session's worktree path
- Support the cyberpunk theme (custom VS Code theme or color overrides)
- Handle auth-less local connection
- Panel resize triggers editor layout recalculation

### Target Version

V1.2
