## AI Assistant Overlay

Replace the assistant placeholder with a contextual overlay that proactively surfaces suggestions, warnings, and next actions based on the current session state.

### Scope

- Overlay panel that reads session context (playbook step, task progress, agreement status)
- Proactive suggestions: "Next step: run /speckit.implement", "Agreement check overdue"
- Drift detection alerts from agreement system
- Feature lifecycle progress indicator
- Quick-action buttons to execute suggested commands

### Target Version

V1.5
