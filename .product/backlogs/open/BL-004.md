## AI Chat Panel

Replace the chat placeholder with a functional chat interface for interacting with Claude. Supports slash commands, markdown rendering, and context-aware conversations scoped to the session's worktree.

### Scope

- Chat input with markdown support and slash command autocompletion
- Message history with user/assistant bubbles in cyberpunk styling
- Integration with Claude API or Claude Code CLI as backend
- Context injection: automatically include session worktree context
- Support for kai slash commands (e.g., `/speckit.implement`, `/agreement.check`)

### Target Version

V1.4
