When the mobile sidebar (Sheet) is open at ≤768px viewport and a user taps a session item, the session is selected (highlighted) but the Sheet remains open. The user must manually close the sidebar to see the main content. This is contrary to standard mobile navigation drawer behavior.

**Root cause** (FB-085):
`MobileNav` does not programmatically close the Sheet when `onSessionSelect` fires. The Sheet is not converted to a controlled component with close-on-select logic.

**Fix**:
In `MobileNav`, convert `Sheet` to a controlled component and close it programmatically when `onSessionSelect` fires:

```tsx
const handleSelect = (id: string) => {
  onSessionSelect(id);
  setOpen(false);
};
```

Pass `handleSelect` as the session select handler instead of `onSessionSelect` directly.

**Acceptance criteria**:
- Given the mobile sidebar sheet is open, when the user taps a session item, the sheet closes automatically and the selected session's main content is visible.
- Session selection still fires correctly (session becomes active/highlighted in the list).
