The Create Session dialog requires two clicks on the close button to actually close. The first click resets the form state but leaves the dialog open; the second click closes it.

**Root cause**: The Radix Select component reset inside `handleOpenChange(false)` triggers a state update that re-opens or holds the dialog open, preventing a single-click close.

**File**: `new-session-dialog.tsx` — `handleOpenChange` function.

**Acceptance criteria**:
- A single click on the X button closes the dialog immediately.
- Form state is still reset when the dialog closes.
- No Radix Select re-render side effect interferes with `DialogContent` open state.
