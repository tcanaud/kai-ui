Bottom row panels in `panel-layout.tsx` rely on CSS Grid auto-placement rather than explicit `col-span-*` classes. This is fragile — adding, removing, or reordering panels could cause unexpected layout shifts without any code change.

**Current behavior**: Bottom row panels have no explicit `col-span` Tailwind classes and depend on grid auto-fill behavior.

**Expected behavior**: All panels should have deterministic grid placement via explicit span classes, making the layout robust to future panel additions and reorderings.

**File**: `panel-layout.tsx` — bottom row panel wrapper divs.

**Fix**:
- Audit all panel wrapper divs and add explicit `col-span-{n}` (and `row-span-{n}` where applicable) Tailwind classes
- Document the intended grid structure with a comment for future maintainers
