The terminal panel displays "Disconnected. Reconnecting..." on initial page load even when the sidecar WebSocket server at port 3001 is healthy. The xterm.js input is present but the panel never completes the initial connection handshake.

**Root Cause Hypotheses**: Session ID mismatch between Next.js render and the WebSocket connection attempt; missing session context in the URL; timing issue where the WebSocket connection is attempted before the session is established on the sidecar.

**Acceptance Criteria**:
- Navigating to `http://localhost:3000` with a running sidecar displays a live terminal with a shell prompt
- The "Disconnected. Reconnecting..." state is not shown when the sidecar is healthy
- WebSocket connection completes on initial page load without requiring a manual refresh
