The xterm.js terminal textarea captures all Tab key presses as terminal input, preventing keyboard-only users from ever moving focus to other UI elements (sidebar, buttons, etc.). This is a WCAG 2.1 failure (SC 2.1.2 — No Keyboard Trap).

**Acceptance Criteria**:
- Pressing Tab while the terminal is focused moves browser focus to the next focusable element outside the terminal
- Pressing Shift+Tab moves focus to the previous focusable element
- The fix does not break normal Tab usage within shell readline (e.g., tab completion should remain accessible via an alternative mechanism or after opt-in)
- Alternatively, an Escape-based exit pattern is implemented (see also FB-020 / BL-026)
