Four accessibility issues in the session creation dialog form (`new-session-dialog.tsx`):

1. **Missing DialogDescription** (FB-047): The Radix `Dialog` has no `DialogDescription`, leaving screen readers without context about the dialog's purpose. Fix: add a `DialogDescription` (e.g. "Fill in the details below to start a new kai session.") wrapped in `VisuallyHidden` if a visible description is not desired.

2. **Broken label association** (FB-048): `<Label htmlFor="playbook">` has no matching `id="playbook"` on any form element. Clicking the label doesn't focus the control. Fix: add `id="playbook"` to the `SelectTrigger` or use the Radix `id` forwarding pattern.

3. **Form errors not announced** (FB-052): Validation and API error messages are rendered visually but lack `role="alert"` or `aria-live="assertive"`, so screen readers do not announce them. Fix: add `role="alert"` to the error container.

4. **SelectTrigger has no accessible name** (FB-053): The playbook `SelectTrigger` has no accessible name because the label association is broken (FB-048). Once FB-048 is fixed this resolves automatically; as an interim fix add `aria-label="Playbook"` directly to the trigger.
