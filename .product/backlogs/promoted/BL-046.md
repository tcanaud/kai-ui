Two mobile/tablet layout issues affecting usability at non-desktop viewports:

1. **Hamburger overlaps terminal panel header** (FB-055): On mobile and tablet, the fixed-position hamburger menu button overlays the terminal panel header, making it inaccessible. The main content area has no top padding to account for the navigation bar height. Fix: add sufficient `padding-top` to the main content area on mobile viewports (using a CSS variable or Tailwind token matching the nav bar height).

2. **Tablet uses mobile single-column layout with wasted space** (FB-056): At 768px (tablet), the app renders the same single-column layout as on phones, wasting horizontal space. No intermediate breakpoint exists between mobile and full desktop. Fix: introduce a tablet breakpoint (Tailwind `md`, 768px) that shows a compact sidebar alongside the main content, leveraging available horizontal space without requiring the full desktop layout.
