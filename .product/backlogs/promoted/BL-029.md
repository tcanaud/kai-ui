The feature name validation regex `^[a-z0-9][a-z0-9-]*$` is too permissive. It accepts trailing hyphens (`trailing-hyphen-`) and consecutive hyphens (`double--hyphen`), both of which produce invalid identifiers that break git branch names, filesystem paths, and slug conventions.

**File**: `new-session-dialog.tsx` line 31.

**Fix**: Update regex to `^[a-z0-9]([a-z0-9]|-(?!-))*[a-z0-9]$` (or equivalent) to disallow trailing and consecutive hyphens. Ensure single-character names remain valid.

**Acceptance criteria**:
- `trailing-hyphen-` is rejected with a descriptive validation error.
- `double--hyphen` is rejected with a descriptive validation error.
- Single-character names (`a`, `1`) remain valid.
- Valid names like `my-feature-123` continue to pass.
