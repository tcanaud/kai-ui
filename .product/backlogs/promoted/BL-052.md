The QA test script `.qa/005-fix-terminal-tab-key-focus-trap-wcag-2-1-2-keyboard-escape/scripts/test-modified-tab-stays-in-terminal.mjs` contains a JavaScript syntax error that prevents the module from loading at all.

**Root cause** (FB-077):
Line 140 contains `const { default: WebSocket: WS2 } = await import("ws");` — invalid JavaScript destructuring syntax. The identifier `WebSocket` was already declared on line 43. The script fails to parse before any test logic executes.

**Fix**:
Remove lines 138–141 entirely. These lines appear to be dead code left behind after refactoring — the script already prints PASS and exits before reaching them, but the syntax error prevents the module from loading at all.

**Acceptance criteria**:
- `node test-modified-tab-stays-in-terminal.mjs` loads and executes without a syntax/parse error.
- All acceptance criteria for feature 005 (US1.AC3) continue to be verified by the script.
